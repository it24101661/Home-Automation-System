# Home-Automation-System
The system demonstrates the implementation of simple automation concepts using microcontrollers and sensors. It includes an Automatic Door System and an Automatic Lighting System designed to improve convenience and energy efficiency.
🏠 Home Automation System
📌 Project Overview

This project is a basic Home Automation System developed as a first-year, first-semester group project for the IT1040 – Fundamentals of Computing module at Sri Lanka Institute of Information Technology.

The system demonstrates the implementation of simple automation concepts using microcontrollers and sensors. It includes an Automatic Door System and an Automatic Lighting System designed to improve convenience and energy efficiency.

🎯 Objectives

To understand the fundamentals of embedded systems

To gain hands-on experience with Arduino/ESP32

To implement sensor-based automation

To develop teamwork and practical problem-solving skills

⚙️ System Components
🔹 Automatic Door System

Arduino Uno / ESP32

Servo Motor

Prototype Door (Cardboard Model)

Jumper Wires

Function:
The door opens and closes automatically based on programmed control logic using a servo motor mechanism.

🔹 Automatic Lighting System

Arduino Uno

PIR Motion Sensor

LED

Jumper Wires

Function:
The lighting system automatically turns on when motion is detected and turns off when no movement is present.
